# FileManager

一个 Windows 控制台文件管理工具，使用 C++17 和 `std::filesystem` 实现，支持 UTF-8 控制台输入与中文路径。

## 当前功能

### 1. 文件搜索

- 递归扫描指定目录下的普通文件。
- 支持按文件名、按文件二进制内容、或两者任一命中的方式搜索。
- 内容搜索采用多线程和分块读取；跨读取块的目标文本也能正确匹配。
- 可仅输出命中文件路径，也可复制命中文件。
- 复制时可选择保留原目录结构，或将文件平铺到结果目录；平铺模式会自动加 `_1`、`_2` 等后缀防止覆盖。
- 每次搜索生成包含路径和复制结果的 UTF-8 日志文件。

### 2. 重复文件清理

- 递归收集目录内普通文件，先按文件大小分组，再逐字节比较二进制内容。
- 只有二进制完全相同的后续文件才会被处理；每组第一次发现的文件保留。
- 删除操作会移入 Windows 回收站，不会直接永久删除。
- 会输出处理数量、回收大小、比较失败数量，并生成日志文件。

### 3. 提取新版目录中的新增和更新文件

用于制作文件更新包。

- 输入目录 A：旧版本（基准目录）。
- 输入目录 B：新版本目录。
- 输入目录 C：输出目录。
- 程序递归扫描 B，并按相对路径查找 A 中的对应文件。
- B 中不存在于 A 的文件判定为新增，复制到 C。
- A、B 中同路径文件会进行实际二进制比较；内容不同则把 B 中的文件复制到 C。
- 二进制完全相同的文件不会复制，即使文件修改时间不同。
- 仅存在于 A 的文件视为“新版已删除”，只写入统计和日志，不会复制到 C。
- C 中保持 B 的原始子目录结构，因此可直接作为新版差异文件包使用。

## 差异提取安全规则

- A、B 必须是存在且不同的目录。
- A 和 B 不能互相包含。
- C 不能等于 A/B，也不能位于 A/B 内部，防止扫描到自身输出或覆盖源文件。
- C 不存在时自动创建；若 C 已存在，则必须为空目录，避免陈旧文件混入本次结果。
- 目录扫描跳过符号链接，避免递归循环。
- 文件读取、二进制比较或复制失败会被记录为失败，不会被误判为“已更新”。

## 源码结构

| 文件 | 职责 |
| --- | --- |
| `main.cpp` | 程序最小入口。 |
| `FileManager.h/.cpp` | 控制台语言选择、主菜单和各功能交互流程。 |
| `FileSearch.h/.cpp` | 多线程文件名/内容搜索及可选复制。 |
| `DuplicateCleaner.h/.cpp` | 重复文件分组、二进制确认和回收站处理。 |
| `DirectoryDiff.h/.cpp` | A/B 二进制差异提取到 C。 |
| `FileSystemUtils.h/.cpp` | Unicode 路径、目录扫描、二进制比较和文件复制等公共能力。 |
| `Localization.h/.cpp` | 中英文文本选择和确认输入判断。 |

## 在 Visual Studio 2026 中使用

1. 双击 `FileManager.sln`，或在 Visual Studio 中打开该解决方案。
2. 选择 `Debug` 或 `Release`，以及 `x64` 或 `x86` 平台。
3. 生成并运行项目。
4. 在菜单中选择功能；选择“提取新版目录中的新增/更新文件”后依次输入 A、B、C。

工程使用 MSVC `v145`、Windows SDK `10.0.26100.0` 和 C++17。生成的程序默认位于：

```text
build\x64\Release\FileManager.exe
```

## 日志与输出

- 搜索日志：`search_results_时间戳.txt`；若选择复制，则日志位于搜索结果目录内。
- 重复文件清理日志：`duplicate_remove_results_时间戳.txt`。
- 目录差异日志：`directory_diff_results_时间戳.txt`。
- 目录差异日志写在程序当前工作目录，不写入 C，确保 C 仅保存新增和更新后的业务文件。
